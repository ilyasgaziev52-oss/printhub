# PrintHub — управление 3D-принтерами в локальной сети

Веб-приложение, которое работает на вашем компьютере (Windows, Linux, macOS или Raspberry Pi)
и управляет принтерами **Bambu Lab, Elegoo и Anycubic**, а также любыми принтерами на **Klipper** и **OctoPrint**.
Интерфейс открывается в браузере на ПК или телефоне.

## Возможности

| | |
|---|---|
| 🔍 **Поиск в сети** | Bambu (SSDP), Elegoo (SDCP и Centauri 2), Anycubic, Klipper и OctoPrint (сканирование подсети) |
| 📊 **Мониторинг** | статус, прогресс, слои, «осталось» и «будет готово в», температуры, вентиляторы, AMS/ACE/CANVAS, ошибки HMS, камера |
| 🖨 **Управление** | загрузка файла, запуск, пауза, продолжение, стоп, подсветка, скорость, G-code (где протокол позволяет) |
| 📁 **Файлы** | библиотека G-code / 3MF / STL / OBJ / файлов смолы, миниатюры, файлы на самом принтере |
| ⏱ **Время и материал** | разбор заголовков OrcaSlicer, Bambu Studio, PrusaSlicer, Cura, Elegoo и Anycubic; собственная симуляция движения с ускорениями; пластины 3MF; заголовки .goo, .ctb, .pwmx, .pm4n, .pm5, .pm7, .pwsz и других |
| 💰 **Себестоимость** | материал, электричество, амортизация, брак, работа, наценка, тираж |
| 🛠 **Подготовка модели** | 3D-просмотр с подсветкой нависаний; поиск дыр, неманифолдных рёбер, вывернутых нормалей, дублей и осколков; ремонт (включая MeshFix); масштаб, поворот, «положить на грань», подбор ориентации, перевод единиц |
| ✂ **Нарезка** | через OrcaSlicer или Bambu Studio CLI (FDM); через PrusaSlicer и UVtools (смола) |
| 📋 **Очередь** | задания для принтеров, автозапуск после кнопки «Стол очищен» |
| 📈 **История** | учёт заданий, часов, расхода и стоимости по принтерам; остаток материала списывается автоматически |
| 🔔 **Уведомления** | Telegram (со снимком с камеры): готово, ошибка, пауза, потеря связи |

## Установка на Windows (рекомендуется)

1. Запустите **`PrintHub-Setup-<версия>.exe`**. Python ставить не нужно: он встроен в программу. Права администратора тоже не нужны.
   - Установщик пока без цифровой подписи, поэтому Windows может показать «Система Windows защитила ваш компьютер». Нажмите **«Подробнее» → «Выполнить в любом случае»**.
2. После установки PrintHub откроется в браузере (`http://127.0.0.1:8080`), а в трее, у часов, появится значок. Меню значка: открыть, адрес для телефона, проверить обновления, автозапуск с Windows, выход.
3. При первом запуске брандмауэр Windows спросит про доступ к сети. Нажмите **«Разрешить»**, иначе с телефона и других компьютеров сайт не откроется.
4. **Автообновление:** программа проверяет новые версии при запуске и каждые 6 часов. Найдя новую, она скачивает её, сверяет контрольную сумму SHA-256, ставит без вопросов и перезапускается. Пока на принтер передаётся файл, обновление ждёт. Печать на самих принтерах от перезапуска PrintHub не прерывается. Статус и кнопка «Обновить сейчас» — в «Настройки → Обновления».

Данные (принтеры, библиотека, история) хранятся в `%LOCALAPPDATA%\PrintHub\data` и сохраняются при обновлении и удалении программы. Журнал работы — `printhub.log` в той же папке.

## Запуск из исходников (Linux, macOS, Raspberry Pi, разработка)

Нужен **Python 3.10+**.

- **Linux / macOS / Raspberry Pi:** `./run.sh`
- **Windows:** `run.bat` (если Python установлен с отметкой «Add to PATH»)

Откроется браузер с адресом `http://127.0.0.1:8080`. С телефона в той же сети откройте адрес, который программа напишет при запуске (например `http://192.168.1.10:8080`).

**Попробовать без принтеров:** `run.bat --demo` (или `./run.sh --demo`) запускает два эмулированных принтера, на которых «идёт» печать, и кладёт в библиотеку пример G-code и модель с дефектами.

Другие параметры: `--port 8080`, `--data папка_с_данными`, `--host 127.0.0.1` (доступ только с этого ПК), `--no-browser`.

> Компьютер с PrintHub должен быть **в той же локальной сети**, что и принтеры. Для камер X1, P2S, H2 и Anycubic нужен [ffmpeg](https://ffmpeg.org/download.html) в PATH.

## Настройка принтеров по брендам

### Bambu Lab (X1, X1E, P1P, P1S, P2S, A1, A1 mini, H2D, H2S, H2C)
1. На экране принтера: **Настройки → Сеть (WLAN)**. Там видны IP-адрес и **код доступа** (Access Code).
2. В PrintHub: «Поиск и добавление» → «Найти» → «Добавить» → введите код доступа. Серийный номер определится сам.
3. **Чтобы запускать, ставить на паузу и останавливать печать**, включите на принтере **«LAN Only» и «Режим разработчика»** (Developer Mode). Так устроено с прошивок 2025 года (Bambu Authorization Control). Без этого режима работают статус, свет, загрузка файлов и камера, а кнопки управления неактивны; PrintHub подскажет это на карточке.
   - В режиме LAN Only не работают Bambu Handy, облако и обновления по сети: прошивку обновляют с флешки.
4. Камера X1, P2S и H2: включите **«LAN Mode Liveview»** в настройках принтера. Камера P1 и A1 работает без дополнительной настройки.
5. Файлы записываются на SD-карту или USB-накопитель принтера: без карты или флешки загрузка невозможна.
6. Печать `.gcode.3mf` из Bambu Studio или OrcaSlicer. Лотки AMS сопоставляются с филаментами проекта автоматически, по типу и ближайшему цвету.

### Elegoo
| Модель | Как подключать |
|---|---|
| Centauri Carbon, Saturn 4 Ultra / 16K, Mars 5 Ultra | тип «Elegoo SDCP», нужен только IP |
| Centauri Carbon 2, Centauri 2 | тип «Elegoo Centauri 2/Carbon 2»; на принтере включите **LAN Only**; код доступа — если задан |
| Neptune 4 / 4 Pro / 4 Plus / 4 Max, OrangeStorm Giga | тип «Klipper (Moonraker)», нужен только IP |
| Neptune 3 и старше (Marlin) | через OctoPrint на Raspberry Pi по USB |
| Saturn 3 Ultra, Mars 4 Ultra | протокол SDCP V1 (MQTT): пока не поддерживаются |

Centauri Carbon «падает» от неизвестных команд, поэтому PrintHub отправляет ему только задокументированные команды SDCP.

### Anycubic
| Модель | Как подключать |
|---|---|
| Kobra 3 / 3 V2 / 3 Max, Kobra S1 / S1 Max, Kobra 4, Kobra X | тип «Anycubic LAN»; на принтере **Настройки → Сеть → LAN Mode** |
| Photon P1 | «Anycubic LAN»: статус, пауза и стоп (запуск и загрузка пока только из Photon Workshop) |
| Photon Mono X, X 6K, SE | тип «Anycubic Photon»: статус, печать, пауза и стоп **файлов с флешки** (протокол не умеет загружать) |
| Kobra с прошивкой Rinkhals | можно выбрать «Klipper (Moonraker)» |
| Kobra, Kobra 2, Kobra 2 Neo, Kobra Max/Plus (Marlin) | через OctoPrint по USB |
| Photon M5s, M7, M7 Pro, M7 Max | только облако Anycubic, локального протокола нет |

⚠ LAN-режим Anycubic отключает облако, приложение и ИИ-камеру, а на S1 с прошивкой 2.7.2.7 ещё и **отвязывает принтер от аккаунта**.

### Klipper и OctoPrint
- **Klipper:** нужен только IP (порт 7125 или 80). API-ключ нужен, только если в Moonraker включена авторизация.
- **OctoPrint:** IP и API-ключ (OctoPrint → Настройки → Application Keys).

## Подготовка и нарезка моделей

Во вкладке «Подготовка модели» загрузите STL, OBJ или 3MF. Там можно:
- посмотреть модель на столе выбранного принтера, с нависаниями, подсвеченными красным;
- найти дефекты и нажать **«Исправить»** (сложные случаи — «Глубокий ремонт» через MeshFix, пересекающиеся тела — «Объединить тела»);
- масштабировать, повернуть, «положить на грань», выбрать ориентацию (минимум поддержек, максимум контакта или минимальная высота), перевести см или дюймы в мм;
- получить оценку расхода, времени и стоимости до нарезки (примерно ±30%).

Каждое действие сохраняет новую версию файла; исходник не меняется.

**Нарезка FDM** выполняется через **OrcaSlicer** (он поддерживает Bambu, Elegoo и Anycubic) или Bambu Studio. PrintHub находит их сам; путь можно задать в настройках.
У OrcaSlicer 2.5+ в установке профили запакованы (`.opc`). Тогда скачайте папку `resources/profiles` **той же версии** с [GitHub OrcaSlicer](https://github.com/OrcaSlicer/OrcaSlicer) и укажите её в «Настройки → Папка профилей».
На Linux AppImage лучше один раз распаковать: `./OrcaSlicer*.AppImage --appimage-extract`.

**Нарезка смолы:** установите бесплатные [PrusaSlicer](https://www.prusa3d.com/page/prusaslicer_424/) и [UVtools](https://github.com/sn4k3/UVtools). PrusaSlicer строит поддержки и режет в `.sl1`, затем UVtools конвертирует в формат принтера (`.goo`, `.ctb`, `.pwmx`, `.pm4n`, `.pm5` и т.д.). Профили принтеров берутся из UVtools.
Можно и не резать в PrintHub: загружайте готовые файлы из Chitubox, Lychee или Photon Workshop, и PrintHub прочитает их время, объём и превью.
Исключение — зашифрованный `.ctb` (Chitubox 2.x): его параметры не читаются. Сохраните файл в `.goo` или узнайте время на принтере.

## Безопасность

- PrintHub предназначен для **локальной сети**. Не открывайте его порт в интернет.
- В «Настройках» можно задать **пароль** (логин — любой).
- Коды доступа принтеров хранятся в `data/printhub.sqlite3` на вашем компьютере.

## Ограничения и статус

Протоколы реализованы по официальным спецификациям (Elegoo SDCP, формат GOO) и по проверенным open-source проектам (ha-bambulab, OpenBambuAPI, elegoo-homeassistant, anycubic_ha_local, UVtools и др.). Код покрыт автотестами на эмуляторах принтеров, но **на реальном оборудовании ещё не проверялся**. Если что-то работает не так, пришлите текст ошибки с карточки принтера или из консоли (`--debug`).

## Для разработчиков

```
printhub/
  app.py            HTTP API + WebSocket (FastAPI)
  manager.py        драйверы, история заданий, очередь, камеры, уведомления
  discovery.py      поиск принтеров в сети
  drivers/          bambu, elegoo (SDCP), elegoo_cc2, anycubic_lan, anycubic_photon, moonraker, octoprint
  analysis/         gcode (заголовки + симуляция), threemf, mesh (анализ/ремонт), resin_files, cost
  slicer.py         OrcaSlicer/Bambu Studio CLI, PrusaSlicer + UVtools
  emulators.py      эмуляторы принтеров (тесты и --demo)
  web/              интерфейс (HTML/JS без сборки, three.js)
tests/              pytest: pip install -r requirements-dev.txt && pytest
```

API доступно по адресу `/docs` (Swagger).

## Выпуск новых версий (для автообновления)

Обновления раздаются через **релизы GitHub**:

1. Создайте репозиторий на GitHub и загрузите в него проект.
2. Выпустите версию: `git tag v0.2.1 && git push origin v0.2.1`. Сценарий `.github/workflows/release.yml` прогонит тесты, соберёт `PrintHub-Setup-0.2.1.exe` и опубликует релиз.
3. Установленные копии PrintHub найдут релиз и обновятся сами. Адрес репозитория встраивается в установщик при сборке (`UPDATE_REPO`).

Установщик можно собрать и вручную, на Linux:

```bash
sudo apt-get install -y nsis gcc-mingw-w64-x86-64 binutils-mingw-w64-x86-64 unzip && pip install pillow
UPDATE_REPO=владелец/репозиторий ./packaging/build_windows.sh 0.2.1
```

Вместо GitHub можно раздавать обновления со своего сервера: укажите в «Настройки → Обновления» адрес JSON-манифеста. Манифест создаётся командой `python -m printhub.updater PrintHub-Setup-0.2.1.exe 0.2.1 https://ваш-сайт/PrintHub-Setup-0.2.1.exe`.
